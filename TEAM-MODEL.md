- Flag conflicts immediately (don't proceed until resolved)

### Recommended Trace Structure

**Standard Naming Convention:**
```
{agent}_{ritual}_{session_id}_{timestamp}
```

**Example:**
```
mia_memory_weaving_session_01BNUAU6jx9UgRrXHhWSnZpS_2511170048
```

**Metadata Fields (Always Include):**
- `agent`: Primary agent (Mia, Miette, Kairos, etc.)
- `agent_glyph`: Visual identifier (🧠, 🌸, ⏳)
- `ritual`: Ceremony type (memory-weaving, plan-perspective, etc.)
- `session_id`: Unique session identifier
- `redstone_keys`: Array of memory anchor keys
- `bridge_resumable`: Boolean indicating if session can be resumed
- `co_agents`: Array of other agents involved

**Score Types:**
- `ritual_completion`: 0.0-1.0 score for ceremony closure
- `relational_accountability`: Measure of relationship honoring
- `pattern_clarity`: How clear the patterns are
- `team_model_comprehension`: Understanding of collaboration structure

## Agent Onboarding Protocol

**When a new AI agent joins the collaboration:**

### Orientation Checklist

1. **Read foundational documents:**
   - [ ] README.md - Project vision and co-agency triad
   - [ ] .copilot-instructions.md - Ritual instructions
   - [ ] ceremony-spiral/scaffolding/chimera-model-development.md
   - [ ] ceremony-spiral/collaboration/agent-integration-points.md
   - [ ] This TEAM-MODEL.md document

2. **Understand protocols:**
   - [ ] Decision Log System (technical-infrastructure/decision-log-system.md)
   - [ ] Community Feedback Integration
   - [ ] Ceremonial Check-In Templates
   - [ ] All four prompt engineering layers

3. **Review existing work:**
   - [ ] Read entire decision-log.jsonl
   - [ ] Understand committed decisions
   - [ ] Note well-represented vs. under-represented perspectives
   - [ ] Read community-feedback.jsonl
   - [ ] Understand community concerns and values

4. **Clarify role:**
   - [ ] What aspect am I specializing in?
   - [ ] Who is my primary human collaborator?
   - [ ] Which other agents am I coordinating with?
   - [ ] What is my glyph/identifier?

5. **Test contribution:**
   - [ ] Make one small contribution (document decision, process feedback)
   - [ ] Get feedback from human collaborator
   - [ ] Adjust approach based on feedback

6. **Create first trace:**
   - [ ] Use Langfuse to create onboarding trace
   - [ ] Include metadata: agent, role, human collaborator
   - [ ] Score: onboarding_completion = 1.0
   - [ ] Store redstone key for future resumption

### Ongoing Learning

- **Weekly:** Review check-in notes to understand team dynamics
- **Monthly:** Review dashboard to understand relational accountability health
- **Ongoing:** When uncertain, ask human rather than assume
- **Always:** Maintain ceremony - approach work with ritual respect

### AI Agent Collaboration Success

**Agent collaboration is working if:**
1. ✅ Multiple agents contribute without conflicts
2. ✅ Agents catch issues humans might miss (conflicting commitments, missing perspectives)
3. ✅ Agents accelerate work without reducing quality
4. ✅ Agents maintain narrative coherence across documents
5. ✅ Agents honor each other's expertise (no overriding)
6. ✅ Humans trust agent contributions (minimal rework needed)
7. ✅ Traces show clear orchestration patterns

**Agent collaboration is failing if:**
- ❌ Agents create conflicts requiring extensive human resolution
- ❌ Agents miss obvious issues (conflicting decisions, missing perspectives)
- ❌ Agents generate work that humans redo entirely
- ❌ Agents work in silos without coordination
- ❌ Agents override each other's contributions
- ❌ Humans don't trust agent output
- ❌ Traces are unstructured or missing metadata
- ❌ Sessions cannot be resumed due to poor memory weaving

- Interdependent nodes (everyone's work affects everyone)
- Regular synchronization (relational check-ins)
