## Key Concepts

### 1. Portfolio Integration

Ceremony Spiral is **not standalone**—it's the integration layer connecting:

- **Tier 1:** Narrative Context Protocol (NCP)
- **Tier 2:** Indigenous AI Integration Protocol (IAIP)
- **Tier 3:** Ceremony Spiral Platform
- **Tier 4:** Creative Intelligence (Music systems)
- **Tier 5:** Multi-Agent Orchestration

See [`scaffolding/portfolio-integration-strategy.md`](./scaffolding/portfolio-integration-strategy.md)

Proven team structure with:

### 3. Relational Accountability

**Every decision documented with:**
- Multiple perspectives considered (technical, community, business, partnership, research, product)
- Relational impact (who is affected, how we honor relationships, what accountability we maintain)
- Reversibility (how easily can we change course, what triggers reconsideration, when we'll revisit)

**Systems:**
- Decision Log (JSONL) - Machine-readable, queryable
- Community Feedback Integration - Real-time community voice shaping product
- Ceremonial Check-Ins - Weekly/monthly reflection
- Relational Accountability Dashboard - Visual display of relationship health

See [`technical-infrastructure/`](./technical-infrastructure/)

**Jerry's core contribution:** Four layers of prompts that maintain relational accountability at scale

- **Layer 1:** Relational Decision Documentation

See [`prompt-engineering/`](./prompt-engineering/)

## How to Contribute

### Decision-Making

1. **During discussions:** Note multiple perspectives being raised
2. **After deciding:** Document using Layer 1 template
3. **Format:** JSONL entry in `decisions/decision-log.jsonl`
4. **Validate:** Against `technical-infrastructure/decision-log-schema.json`
5. **Share:** With affected stakeholders
6. **Revisit:** Honor the revisit date; put on calendar

See [`technical-infrastructure/decision-log-system.md`](./technical-infrastructure/decision-log-system.md)

### Community Feedback

1. **Receive:** Community member shares concern/idea
2. **Document:** Within 24 hours in `decisions/community-feedback.jsonl`
3. **Integrate:** Team discusses "how do we integrate?" (not "should we?")
4. **Follow up:** Within 2 weeks, close the loop
5. **Learn:** Capture what we learned

See [`technical-infrastructure/community-feedback-integration.md`](./technical-infrastructure/community-feedback-integration.md)

### Ceremonial Check-Ins

**Weekly (Every Friday, 30 minutes):**
- Opening acknowledgment
- "Did we practice what we preach this week?"
- Review decisions made
- Celebration & learning
- Closing commitment

**Monthly (Last Friday, 90 minutes):**
- Relational accountability audit
- Perspective balance analysis
- Structural tension assessment
- Ceremony as method check
- Next month planning

See [`technical-infrastructure/ceremonial-checkin-template.md`](./technical-infrastructure/ceremonial-checkin-template.md)
